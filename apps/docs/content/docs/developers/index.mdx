## In short

- **A site is a clone of the repository.** The web app in `apps/web` is source code you own and can change.
- **It needs three things:** Node.js, a database (a SQLite file or PostgreSQL) and S3-compatible storage for uploads. Email is optional.
- **Plugins are npm packages** built on `@pet-adopt/plugin-sdk`, listed in `apps/web/pet-adopt.config.ts`.
